# Optional extras for Moon's Wardrobe

Tick the ones the client wants next. Each is outside the current demo build.

## Orders and delivery

- [ ] Courier booking from the admin panel: Steadfast or Pathao API (create a parcel, print the label, sync the status)
- [ ] Real delivery charges by courier zone and weight, instead of the flat ৳80 / ৳150
- [ ] Order confirmation and status emails (e.g. Resend or Amazon SES)
- [ ] SMS on order placed / shipped / delivered (BulkSMSBD, SSL Wireless or Alpha SMS)
- [ ] Invoice PDF download for each order
- [ ] Exchange / return requests from the track-order page

## Payments

- [ ] SSLCommerz checkout (cards, mobile banking, internet banking)
- [ ] bKash Tokenized Checkout (direct merchant API)
- [ ] Nagad merchant API
- [ ] Partial advance for COD outside Dhaka (e.g. delivery charge paid in advance)

## Customers

- [ ] OTP login by phone number (no passwords)
- [ ] Customer accounts: saved addresses, order history, wishlist synced across devices
- [ ] Real product reviews with photos, moderated in the admin panel
- [ ] "Notify me when back in stock"

## Catalog

- [ ] Stock per product (and "only 1 left"), with stock checked at checkout
- [ ] Product variants for the same weave in several colours
- [ ] Blouse stitching service with measurements
- [ ] Gift wrap and gift note
- [ ] Bulk CSV import / export of products

## Marketing

- [ ] Facebook Pixel and Conversions API (ViewContent, AddToCart, Purchase)
- [ ] Facebook / Instagram catalog feed (`/feed.xml`) for Shops and dynamic ads
- [ ] Google Analytics 4 and Google Merchant Center feed
- [ ] Server-side rendering or prerendered product pages for richer link previews and SEO
- [ ] Newsletter sending (Mailchimp or Brevo sync from the subscriber list)
- [ ] Festival landing pages (Eid, Pohela Boishakh, Puja) editable in the admin panel

## Operations

- [ ] Several admin users with roles (owner, staff)
- [ ] Admin activity log
- [ ] Daily database backup from MongoDB Atlas
- [ ] Uptime monitor for the API (UptimeRobot or Better Stack)
- [ ] Custom domain and email for the brand
